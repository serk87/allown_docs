# Allown docs

Правила работы с репозиториями находятся в `product/repository-workflow.md`. Читай их перед изменением процесса разработки или выпуска.

- Этот репозиторий хранит требования, планы и решения между компонентами. API-контракты и эксплуатационные скрипты принадлежат backend; каталог компонентов — UI kit.
- При изменении решения обновляй его основной документ и ведущие к нему ссылки. Устаревшее правило помечай заменённым; не оставляй противоречащие активные инструкции.
- Отделяй проверенные факты и выпущенное поведение от планов. Имена будущих репозиториев не являются подтверждением remote или доступа.
- В документацию не помещай секреты, пользовательские сессии и содержимое пользовательских проектов. Для примеров используй тестовые данные.
