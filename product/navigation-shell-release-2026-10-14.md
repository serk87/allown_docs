## Поведение

Боковая панель и верхний каркас находятся на уровне App и сохраняются на всех внутренних маршрутах, включая проекты, задачи, циклы, входящие и настройки. Контекст и действия верхней панели зависят от раздела. Авторизация и первичное создание пространства остаются отдельными экранами.

Русский — текущий язык. Строки вынесены в словари ru/en; переключатель языка пока не добавлен. Подсказки сочетаний клавиш из панелей удалены. Нижняя кнопка подписана «Настройки» и открывает настройки пространства.

Работают переключение/создание пространства, создание проекта, настройки названия/описания/значка/цвета проекта, выход, поиск, общие/личные задачи, фильтры и сортировка. Настройки проекта сохраняет API только для владельца/тимлида текущего пространства с проверкой CSRF. Проектный список всегда ограничен projectId. Прямое открытие задачи использует реальные детали API. Входящие загружаются из API уведомлений.

Календарь показывает задачи по срокам с переходом между месяцами; хронология группирует задачи по срокам. Это не диаграмма зависимостей или редактор сроков перетаскиванием.

- Backend: go test ./... и Linux-сборка API в golang:1.23-alpine. Проверены роль, отсутствие сессии, CSRF, недопустимый значок и доступ из другого пространства.
- Старый тест TestHandlerRejectsWorkspaceMismatch падал и на исходном HEAD: он ожидал фиксированное default-пространство. Заменён проверкой использования пространства аутентифицированной сессии.
- Production: оба изменённых контейнера healthy, /healthz отвечает ok, анонимная сессия — 401; ENABLE_DEV_SESSION=false, SEED_DEV_DATA=false.
- Через опубликованный интерфейс создан отдельный тестовый проект; сохранены смешанное русско-английское имя, значок и цвет, проверено сохранение после reload. Создана задача, найдена через глобальный поиск, открыты реальные детали, проверены общие панели на странице настроек. Тестовые проект, задача и их событие затем удалены по точным идентификаторам с транзакционными проверками.

## Эксплуатация и откат

Релиз: /srv/task-tracker/releases/navigation-shell-20261014. Манифест NAVIGATION-RELEASE.txt содержит SHA исходников и хеши артефактов. Обновлены только api и app-web; landing, worker, postgres, redis и другие приложения не обновлялись. Миграции не добавлялись.

На диске было 2,5 ГБ свободно. Использованы готовая локальная web-сборка и Linux-бинарник API, небольшие слои поверх прежних runtime-образов; очищен только созданный этой задачей временный Go-кэш. После выпуска свободно 2,3 ГБ. Перед последующими крупными Docker-сборками нужно освободить восстановимые ресурсы Allown или увеличить диск.

Резервная копия: /srv/task-tracker/shared/backups/navigation-shell-20261014.dump, рядом SHA256 и проверенный список pg_restore. Предыдущий релиз: /srv/task-tracker/releases/workspace-onboarding-20261014. Прежние образы сохранены как allown-web:before-navigation-20261014 и allown-api:before-navigation-20261014; исходные task_tracker_mvp-*:latest также не перезаписывались.

Текущий запуск использует compose-файл backend/infra/docker/docker-compose.production.yml, env/preview.env и дополнительный navigation-images.yml из каталога релиза. При откате запустить api и app-web через compose предыдущего релиза с его env, --no-deps --no-build, затем вернуть current на предыдущий каталог и проверить health. БД для отката этого релиза восстанавливать не требуется: схема не менялась.
